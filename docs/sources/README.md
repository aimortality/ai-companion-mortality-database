# Source Documentation

This directory contains organized references to primary sources underlying the AI Companion Mortality Database. 

Each case in our database is supported by verifiable documentation. This index provides pathways to that evidence for researchers, journalists, and the public.

## How to Use These Sources

### For Researchers

Each source entry includes:
- Full citation in appropriate format
- Access information (paywall status, PACER fees, etc.)
- Date accessed for web sources
- Archive links where available (Internet Archive, Perma.cc)

### For Journalists

Sources are organized to facilitate independent verification:
- Primary documents listed first
- Secondary reporting listed with outlet and byline
- Contact pathways for family representatives where publicly available

### For Legal Professionals

Court documents include:
- Case numbers and jurisdictions
- Docket status as of last update
- Links to PACER or state court systems
- Notable rulings with page citations

## Source Integrity

We maintain source integrity through:

1. **Archive preservation**: Key documents archived via Internet Archive and Perma.cc
2. **Local backup**: Critical court filings stored in project repository where permitted
3. **Access notes**: Paywall and access limitations documented
4. **Version tracking**: When sources are updated or corrected, we note the change

---

## Contributing Sources

If you have access to relevant primary documents not yet in our index:

1. Open an issue on the [project issue tracker](https://gitlab.com/aimortality/ai-companion-mortality-database/-/issues) with "Source Contribution" label
2. Describe the document and its relevance
3. Provide access pathway or offer to share (respecting legal constraints)
4. We will verify and add with appropriate credit

Particularly valuable:
- Court documents from ongoing cases
- Non-English language sources with translation
- Academic preprints or working papers
- Regulatory correspondence obtained via FOIA

---

## A Note on Access

Some sources in this index require payment or credentials to access:

- **PACER** (federal court documents): $0.10/page, capped at $3.00/document
- **News paywalls**: Noted where applicable; many libraries provide access
- **Academic journals**: DOI links provided; many available through institutional access

We believe in open access and link to free alternatives where they exist. Where they do not, we describe the source sufficiently for those with access to locate it.
